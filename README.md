# BreastCancer-XAI

## Hybrid EfficientNet-B3 and Swin-Tiny Transformer for Breast Histopathology Cancer Classification with Explainable Artificial Intelligence (XAI)

### Project Overview

This research project focuses on breast cancer histopathology image classification using deep learning and Explainable Artificial Intelligence (XAI).

The project explores a hybrid deep learning architecture integrating EfficientNet-B3 and Swin-Tiny Transformer to capture complementary image features for classification.

### Key Technologies

- Python
- PyTorch
- EfficientNet-B3
- Swin-Tiny Transformer
- Deep Learning
- Computer Vision
- Explainable AI (XAI)

### Explainable AI Techniques

- Grad-CAM
- Grad-CAM++
- SHAP
- LIME

### Research Objectives

1. Develop a hybrid deep learning architecture.
2. Classify breast histopathology images.
3. Evaluate model performance.
4. Analyze model predictions using XAI.
5. Compare explainability methods.

### Results and Visualizations

The results directory contains model evaluation metrics, training histories, confusion matrices, ROC curves and XAI visualizations.

### Dataset

The dataset is not included in this repository. Users must obtain the dataset from its authorized source and configure the appropriate paths.

### Disclaimer

This project is intended for academic research and educational purposes only. It is not a clinically validated diagnostic system and must not be used as a substitute for professional medical diagnosis.
